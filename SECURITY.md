# Security Policy

## Scope

`app/backend/` is intentionally vulnerable and its documented command injection, obsolete packages, debug mode, and root-container behavior are not reportable defects. It must not be deployed publicly or provided real credentials.

Unexpected vulnerabilities in `app/remediated/`, the CI configuration, infrastructure examples, or repository evidence hygiene are in scope.

## Reporting

Please use GitHub's private security-advisory reporting flow for this repository when it is available. Do not include working credentials, personal data, or active infrastructure identifiers in a public issue.

This is a decommissioned portfolio lab, not a supported production service, so no response-time commitment is offered.
